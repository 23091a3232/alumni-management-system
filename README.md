# 🎓 Alumni Management System

A simple web-based Alumni Management System developed as a mini-project for **Experiment 8 – Team Collaboration Using GitHub**.

## 📌 Project Description

The Alumni Management System helps colleges manage alumni information, maintain contact details, and organize alumni events.

It provides a user-friendly interface to add, view, update, delete, and search alumni records.

## 🎯 Objectives

- Manage alumni profiles and contact information.
- Maintain alumni records efficiently.
- Organize alumni events.
- Understand GitHub collaboration and version control.
- Learn teamwork through GitHub.

## ✨ Features

- Add alumni profiles
- View alumni details
- Update alumni information
- Delete alumni records
- Search alumni by name or department
- Manage alumni events
- Maintain contact directory
- Dashboard with statistics

## 🛠️ Technologies Used

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start managing alumni profiles and events.

No additional software installation is required.
